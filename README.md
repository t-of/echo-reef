# ECHO REEF — 鳴らして沈んだ岩を探す

海の底に沈んだ岩を、マスを鳴らして探す推理パズル。返ってくるのはいちばん近い岩までの距離だけなので、いくつもの音を重ねて、少ない回数で岩の場所を全部当てる。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/echo-reef/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. マスを **鳴らす** と、そこから **いちばん近い岩までの距離** が返る。距離は縦と横の歩数の合計。方角は分からない。
2. 距離 3 なら「3 より近くに岩は無い」「ちょうど 3 の菱形の輪の上に、少なくとも 1 つある」。音を重ねて場所を絞る。
3. 岩だと思うマスに **印** を置き、岩の数だけ置いたら **確定**。鳴らした回数が少ないほどよい。外れると +5 回（どれが違うかは教えない）。

- 距離 0 のマスは岩の上。自動で「見つけた岩」の印が付く（外せない）。
- 同じマスをもう一度押しても回数は増えない（輪を出し直すだけ）。
- **今日の海**: 沖 7×7・岩 4。端末の日付から盤を作るので、同じ日ならどの端末でも同じ盤。記録は最初に当てた回数だけ残る。
- **深さを選ぶ**: 浅瀬 6×6・岩 3 / 沖 7×7・岩 4 / 深海 8×8・岩 5 / 海淵 9×9・岩 6。
- **沈める**（手助け）: 岩が無いと決まったマスを薄くする。タイトルの下で切れる。
- 「はじめて」から手引き 4 問を解ける。途中で閉じても続きから遊べる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 0 --bind 127.0.0.1   # 出た番号で http://127.0.0.1:<番号>/ を開く
node test.mjs                                # 決まりのテスト（距離・鳴らす・沈める・確定・日替わり・保存・手引き）
```

- `logic.js`: 決まり（画面に触らない）。`main.js`: 画面と音。`test.mjs`: logic.js のテスト。
- 保存: `echo-reef.settings` / `echo-reef.records` / `echo-reef.resume`（端末の中だけ）。
